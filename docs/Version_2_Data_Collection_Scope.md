# Job Market Intelligence Project

## Version 2 Scope

### Version Goal

Version 2 focuses on upgrading the first version of the project by increasing the dataset size, expanding job roles, and including more countries while keeping the same project architecture and workflow.

### Target Dataset Size

* Minimum target: **1000+ job postings**
* Future goal: expand to a significantly larger dataset for stronger analytics and model performance.

### Focus Area

This version focuses specifically on **Data and AI-related roles** to maintain a strong and focused project scope.

### Job Roles

The following job roles will be included:

* Data Analyst
* Data Scientist
* Data Engineer
* Machine Learning Engineer
* AI Engineer
* Business Intelligence Analyst
* Analytics Engineer
* MLOps Engineer
* Data Architect

### Countries

The analysis will focus on job postings from the following countries:

### Why Version 2

The main objective of Version 2 is to improve project quality by:

* Increasing dataset size for better analytics
* Improving machine learning reliability
* Enabling stronger market comparisons across countries
* Generating more meaningful business insights
* Building a more professional and portfolio-grade project

### Project Workflow

The project will continue using the same workflow established in Version 1:

Raw Data
→ Preprocessing / Cleaning
→ Skills / Tools / Technology Extraction
→ Processed Tables
→ EDA / Business Insights
→ Power BI Dashboard
→ Machine Learning Model
